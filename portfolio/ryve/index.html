Overview

A demo, not a client — used to sell the platform itself.

Ryve is a demo storefront running on Shopzo — a fictional shop, not a real business. It exists purely to walk prospective shop owners through the actual buying experience: browsing, cart, checkout and payment, all live and working on real Shopzo infrastructure, before they commit to their own store.

Key features

What the demo actually shows.

01

General-purpose storefront

A neutral product catalogue and layout, built to demonstrate the platform's defaults rather than one brand's specific style.

02

Working checkout

A real cart and checkout flow, including Bancontact and Payconiq via Mollie, exactly as a live customer would experience it.

03

Seller dashboard access

Prospects can see how products, stock and orders are managed from the seller side, not just the storefront.

04

A starting point, not a template

Ryve shows the platform's baseline — every real storefront, like Loam Living, is then styled to the client's own brand.
