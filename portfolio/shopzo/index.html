Shopzo

A webshop for your business, live in days, not months — the white-label e-commerce platform behind local shops in and around Antwerp.

Visit shopzo.be ↗ See it live: Happy Paws Store ↗

Overview

Shopzo lets small, independent shops sell online without hiring an agency or wrestling with plugins. AGV IT designs and builds each storefront, while shop owners manage products, stock and orders from a single dashboard — hosting, security and updates handled quietly in the background. The platform is multi-tenant: one codebase serving multiple branded storefronts, each with its own domain, products and dashboard access.

Key features

01

Multi-tenant architecture

One platform, many independent storefronts — each shop gets its own branded domain, catalogue and dashboard, isolated from the others.

02

Seller dashboard

Shop owners add products, track stock and see every order land in one place — no spreadsheets, no separate tools.

03

Belgian payments, built in

Bancontact and Payconiq ready from day one via Mollie — payment methods customers already know and trust.

04

Atomic stock handling

Stock decrements run through a Supabase RPC function on order confirmation, so simultaneous orders never oversell an item.
