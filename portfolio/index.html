Loam Living

"Wonen, teruggebracht tot het wezenlijke." — a fictional Dutch-language home-decor shop built on Shopzo, selling handmade ceramics, linen, rattan and oak.

View the concept ↗ See the Shopzo platform →
Overview

A second demo, showing a different tone on the same platform.

Loam Living is a fictional storefront running on Shopzo — used to show how the same platform can carry a completely different look and feel from Ryve. Where Ryve demonstrates the general dashboard and checkout flow, Loam Living leans into a warm, editorial brand: natural materials, small-batch products, and copy written entirely in Dutch for a local audience.

Key features

What the concept actually shows.

01

Category-led catalogue

Products organised into Keramiek, Textiel and Hout & rotan — a clear, materials-first way to browse a small collection.

02

Dutch-first copy

Every line, from the hero to the footer, is written in Dutch for a local Belgian audience rather than translated from a template.

03

Trust strip built in

Free shipping over €60, small handmade runs, and a 30-day return window, surfaced directly under the collection.

04

Shopzo dashboard underneath

Wishlist, cart and login all run on the same Shopzo infrastructure as every other storefront on the platform.
