Overview

A concept built for a BNI Kapellen showcase.

hansi ombregt architectuur designs contemporary new builds and renovations — homes, apartments and pavilions — from a studio in Schoten. This concept site was originally built as a showcase piece for BNI Kapellen: a restrained, image-led layout that lets the architectural work speak for itself, with a clear path from portfolio to first conversation.

Key features

What the concept actually does.

01

Project-led homepage

Large, full-bleed photography of built work leads the page, in a restrained black-and-white palette that suits the discipline.

02

New build & renovation, side by side

The two core services are presented as distinct paths, so a visitor self-selects before reaching the portfolio.

03

Process, made visible

A short breakdown of how a project moves from first sketch to permit to build, setting expectations before the first call.

04

Direct contact, no friction

A simple contact path with no intake form to fill in first — architecture decisions start with a conversation, not a questionnaire.
